# RECT BLASTER v7

v7は、v6で発生した「ゲームスタート直後にゲームオーバーになる」バグを修正した版です。

## v7での主な修正

- スタート直後のゲームオーバー暴発を修正
- 通常フレームではゲームオーバー判定をしない仕様に変更
- ブロックが1段落下した直後だけ危険ライン判定を実行
- 危険ラインに実際にブロックが到達した時のみゲームオーバー
- v6の「少しクォース風に近づけた難易度調整」は維持

## 遊び方

PC操作：

- 左矢印キー：左移動
- 右矢印キー：右移動
- Space：ブロック弾を発射
- P：一時停止
- R：リスタート

スマホ操作：

- 左ボタン：左移動
- SHOTボタン：発射
- 右ボタン：右移動
