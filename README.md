# RECT BLASTER

縦スクロール型のブロックシューティングパズルゲームです。

上から落ちてくる欠けた形のブロックに、下から1マス分のブロック弾を撃ち込み、正方形または長方形を完成させると消えます。

## 重要な注意

このゲームは、既存ゲームの名称・ロゴ・画面デザイン・音楽・効果音・演出を使用しない、完全オリジナルのブラウザゲームとして制作する前提です。

## 遊び方

PC操作：

- 左矢印キー：左移動
- 右矢印キー：右移動
- Space：ブロック弾を発射
- P：一時停止
- R：リスタート

スマホ操作：

- 左ボタン：左移動
- SHOTボタン：発射
- 右ボタン：右移動

## ルール

- 上から欠けた形のブロック群が落ちてきます。
- プレイヤーは画面下部の砲台を左右に動かします。
- 発射する弾は通常弾ではなく、1マス分のブロックです。
- 弾が落下ブロックに当たると、弾の位置にブロックとして固定されます。
- 接続されたブロック群が、穴や欠けのない正方形・長方形になると消えます。
- 消したブロック数と面積に応じてスコアが加算されます。
- ブロックが最下段に到達するとゲームオーバーです。
- 最高スコアはブラウザのlocalStorageに保存されます。

## GitHubへのアップロード方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内のファイルをすべてアップロードします。
3. `index.html` がルート直下にある状態にします。

## Netlifyでの公開方法

1. Netlifyにログインします。
2. 「Add new site」→「Import an existing project」を選びます。
3. GitHubリポジトリを選択します。
4. Build commandは空欄でOKです。
5. Publish directoryは `.` のままでOKです。
6. Deployを押します。

`netlify.toml` を入れているため、基本的にはそのまま公開できます。
