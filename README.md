# RECT BLASTER v4.5 Touch Control

v4.3 Guide Lineのゲームロジックはそのままに、スタート画面の説明文だけをプレイヤー向けに修正した版です。

## v4.3での主な変更

- v4系の安定ロジックを維持
- ゲームオーバー判定はv4系のまま
- ブロックサイズはv4.2の小さいまま維持
- 落ちてくるブロック数の増加スピードを少し緩く調整
- 出現間隔の短縮スピードを緩やかに変更
- 同時出現数の増加も少し緩やかに変更
- プレイヤーの真上に照射ガイドを追加
- 照射ガイドにより、どの列を狙っているか分かりやすく調整

## 照射ガイドについて

プレイヤーの真上に、薄い縦ラインが表示されます。

これは当たり判定には影響しません。
あくまで「今どの列を狙っているか」を分かりやすくするためのガイドです。

## 遊び方

PC操作：

- 左矢印キー：左移動
- 右矢印キー：右移動
- Space：ブロック弾を発射
- P：一時停止
- R：リスタート

スマホ操作：

- 左ボタン：左移動
- SHOTボタン：発射
- 右ボタン：右移動

## GitHub / Netlify

このフォルダをGitHubにアップし、Netlifyでリポジトリを選択すれば公開できます。

Build commandは空欄でOKです。
Publish directoryは `.` です。


## アイコン設定について

この版では、index.html の head 内に以下の設定を組み込み済みです。

- favicon-16x16.png
- favicon-32x32.png
- apple-touch-icon.png
- site.webmanifest

そのため、このフォルダ内のファイルをGitHubにそのままアップロードすれば、Netlify反映後にファビコンとiPhoneホーム画面用アイコンが認識されます。

反映されない場合は、ブラウザやiPhoneのキャッシュが残っている可能性があるため、数分待つか、シークレットウィンドウで確認してください。


## v4.4 Mobile Fit

iPhone Safariで画面下の操作ボタンが切れる問題を修正しました。

主な変更：

- 100vh依存をやめ、100svh / 100dvh に対応
- ゲーム画面の高さをiPhoneの表示領域に合わせて自動調整
- スコア欄・タイトル・ボタンの余白をレスポンシブ化
- Safariのアドレスバー・下部ツールバーがある状態でも、操作ボタンが画面内に収まるように調整
- ゲームロジックは変更なし


## v4.5 Touch Control

スマホ向けの操作を追加しました。

追加操作：

- ゲーム画面をタップ：ブロック発射
- ゲーム画面を左右にスワイプ：プレイヤー左右移動
- 既存の左右ボタン・SHOTボタンもそのまま使用可能

誤操作防止：

- 縦方向のスワイプは無視
- 小さな動きはタップとして判定
- ゲームロジックは変更なし
