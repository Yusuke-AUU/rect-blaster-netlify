# RECT BLASTER v5

v5は「速度で難しくする」のではなく、「必要ショット数と判断量で難しくする」調整版です。

## v5での主な修正

- groupId方式はv4から継続
- 落下速度の上昇をかなり緩やかに変更
- レベルアップで必要なショット数が増えるように変更
- 序盤：1〜2発で消える
- 中盤：2〜3発で消える
- 後半：3〜4発必要な形が出る
- 大きめの長方形を追加
- 同時出現数をレベルに応じて増加
- レベルに応じて弾の最大数も3発→4発→5発に増加
- 大きい四角形のボーナスを強化

## 遊び方

PC操作：

- 左矢印キー：左移動
- 右矢印キー：右移動
- Space：ブロック弾を発射
- P：一時停止
- R：リスタート

スマホ操作：

- 左ボタン：左移動
- SHOTボタン：発射
- 右ボタン：右移動
