# RECT BLASTER v6

v6は、v5で残っていた「突然ゲームオーバーになる」問題を修正し、よりクォース風の見極め型ゲームに近づけた版です。

## v6での主な修正

- ゲームオーバー判定を修正
- 危険ラインに実際に到達した時だけゲームオーバー
- 落下速度だけで難しくする方針をやめ、判断量と必要ショット数で難しく調整
- 序盤から2発必要な形を増加
- 中盤以降は3〜5発必要な形も出現
- 一部、中段の欠けも出るように変更
- ただし、中段の欠けは下から順番に撃てば必ず埋められる形だけに限定
- 同時出現数を少し増加
- クォース風に「どこを埋めれば四角形になるか」を見極める方向に調整

## 遊び方

PC操作：

- 左矢印キー：左移動
- 右矢印キー：右移動
- Space：ブロック弾を発射
- P：一時停止
- R：リスタート

スマホ操作：

- 左ボタン：左移動
- SHOTボタン：発射
- 右ボタン：右移動
