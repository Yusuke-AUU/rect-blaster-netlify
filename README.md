# RECT BLASTER v4.2 Small Block

v4.1 Stableをベースに、ブロックサイズを小さくして、よりクォース風の感覚に近づけた版です。

## v4.2での主な変更

- v4系の安定したgroupId方式を維持
- v4系のゲームオーバー判定を維持
- グリッドを10×20から14×24へ変更
- 1マスを30pxから22pxへ縮小
- 画面サイズは大きく変えず、ブロックだけ細かく
- 小さいブロックをテンポよく撃ち込む感覚に調整
- 形状を横幅3〜8マス中心に再調整
- 序盤から2発程度必要な形を増加
- レベルが上がると3〜5発必要な形も出現
- 同時出現数を少し増加

## 狙い

以前の版は1マスが大きく、パズルブロックを大きく埋める感覚が強めでした。

v4.2では、マスを小さくして、細かいブロックを撃ち込む感覚に寄せています。

これにより、より昔の縦スクロール型ブロックシューティングパズルに近い操作感を目指しています。

## 遊び方

PC操作：

- 左矢印キー：左移動
- 右矢印キー：右移動
- Space：ブロック弾を発射
- P：一時停止
- R：リスタート

スマホ操作：

- 左ボタン：左移動
- SHOTボタン：発射
- 右ボタン：右移動
