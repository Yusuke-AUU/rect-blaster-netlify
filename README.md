# RECT BLASTER v4.3 Guide Line

v4.2 Small Blockをベースに、落ちてくるブロック数の増加スピードを少し緩くし、照射ガイド機能を追加した版です。

## v4.3での主な変更

- v4系の安定ロジックを維持
- ゲームオーバー判定はv4系のまま
- ブロックサイズはv4.2の小さいまま維持
- 落ちてくるブロック数の増加スピードを少し緩く調整
- 出現間隔の短縮スピードを緩やかに変更
- 同時出現数の増加も少し緩やかに変更
- プレイヤーの真上に照射ガイドを追加
- 照射ガイドにより、どの列を狙っているか分かりやすく調整

## 照射ガイドについて

プレイヤーの真上に、薄い縦ラインが表示されます。

これは当たり判定には影響しません。
あくまで「今どの列を狙っているか」を分かりやすくするためのガイドです。

## 遊び方

PC操作：

- 左矢印キー：左移動
- 右矢印キー：右移動
- Space：ブロック弾を発射
- P：一時停止
- R：リスタート

スマホ操作：

- 左ボタン：左移動
- SHOTボタン：発射
- 右ボタン：右移動
